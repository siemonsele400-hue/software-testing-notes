## 使用说明

这套笔记不是逐字稿，而是以视频为主线、按知识主题重组的学习资料。内容分为：

- **课程原讲**：视频中明确讲解的知识。
- **基础补充**：理解课程必须掌握但视频讲得不完整的基础。
- **企业实战**：真实项目中的流程、模板、协作、排查和风险控制。
- **就业重点**：岗位能力、简历项目、笔试和面试表达。
- **进阶扩展**：对后续发展有帮助，但不是零基础第一阶段必学的内容。

练习题采用“题目后立即给出答案和解析”的格式，并同时整理课程原题与补充实操题。

## 学习顺序

```text
基础理论
-> 测试流程与需求分析
-> 测试用例设计
-> 测试计划、Bug 与报告
-> 项目实战
-> 网络、Linux、MySQL
-> JMeter 接口测试
-> Requests/Pytest 接口自动化
-> Selenium Web 自动化
-> 性能测试
-> Git、CI/CD、Docker、可观测性与面试
```

贯穿全课程的质量闭环：

```text
需求 -> 测试点 -> 测试用例 -> 测试数据 -> 执行 -> Bug -> 回归 -> 报告 -> 发布判断
```

## 学习建议

1. 先读 02～04，建立测试术语、流程和用例设计基础。
2. 用登录/注册、ATM、三角形和金融项目资料练习测试点与用例。
3. 掌握 SQL、Linux 和 HTTP 后，再学习接口和自动化。
4. 自动化重点放在分层、稳定性、数据隔离和报告，而不是只会录制脚本。
5. 性能测试必须在授权环境完成，先验证业务正确，再分析负载结果。
6. 每学完一个专题，产出一个可以放进作品集的结果：用例、Bug、SQL、接口脚本、自动化报告或性能报告。
