# 软件测试学习笔记

这是一个面向软件测试就业学习的知识点总结仓库，内容根据课程视频、配套课件和学习过程中的补充资料整理而成。

## 学习目标

- 掌握软件测试的基础概念、测试流程和常用方法。
- 建立从需求分析、测试设计、用例编写到缺陷管理的完整思维。
- 补充实际工作中常用的测试技能，为后续项目实战和求职面试做准备。

## 当前内容

```text
知识点总结/
└─ 阶段一/
   └─ 第一章测试基础.md
```

`第一章测试基础.md` 主要整理软件测试入门阶段的核心知识，并补充就业实践中需要掌握的内容。文档中还包含练习题、参考答案和实践任务，适合按章节复习和自测。

## 使用建议

1. 先通读章节内容，理解概念之间的关系。
2. 根据示例整理自己的测试思路和术语表。
3. 独立完成文档末尾的练习题与实践任务，再对照参考答案复盘。
4. 将后续课程按“阶段 → 章节 → 知识点总结”的结构持续补充。
