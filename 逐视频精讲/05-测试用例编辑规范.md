# 第 05 集：测试用例编辑规范

> **本集核心**：测试用例是“输入/条件 + 操作 + 预期结果”的可执行文档。视频重点讲了用例的重要性、以测试需求为依据、Excel 字段和八大要素，以及为什么要让别人也能照着执行。

## 一、什么是测试用例

测试用例（Test Case）不是一句“测试登录”，而是一组可重复的验证说明。它至少要让执行者知道：用什么账号和数据、处于什么前置条件、点击或调用什么、每一步应看到什么结果。

一个好的用例满足：目的明确、步骤可执行、预期可判断、数据可复现、与需求可追溯。它服务于首次测试、回归测试、交接和审计。

## 二、企业常见八大要素

课程资料中的模板包含以下字段：

1. **用例编号**：唯一，如 `LOGIN-ST-001`；
2. **模块**：用户管理/登录；
3. **用例标题**：概括验证目标；
4. **优先级**：高/中/低或 P0/P1/P2；
5. **前置条件**：账号、数据、环境和权限；
6. **测试步骤**：按顺序写清路径和动作；
7. **预期结果**：每一步及最终结果；
8. **实际结果/备注**：执行时填写，记录证据、Bug 编号和版本。

有些团队还会增加设计者、版本、执行人、日期、需求编号、测试类型和自动化标记。字段多不是目标，关键是能支持协作和追溯。

## 三、标题、步骤和预期怎么写

### 标题

避免“验证注册功能”这种过于宽泛的标题。推荐“在有效手机号和符合规则密码下注册成功并生成用户记录”，读者能立即知道测试目的和条件。

### 步骤

步骤写用户或调用者做什么，不把预期混进动作里：

1. 进入用户管理→注册页面；
2. 输入未注册手机号 `13800000001`；
3. 输入符合规则的密码和验证码；
4. 点击“注册”。

### 预期

预期应可观察、可判定，必要时拆成页面、接口和数据三层：按钮进入提交中；接口返回业务码 0；页面跳转登录页；数据库新增一条启用用户记录。

## 四、优先级如何判断

- **高**：核心主流程、资金、权限、登录、数据安全和冒烟用例；
- **中**：常见异常、错误提示、可恢复流程；
- **低**：视觉细节、低频兼容性和非阻断体验问题。

优先级不是缺陷严重程度。一个低频安全漏洞仍可能是高风险 Bug；优先级表示时间有限时先执行什么。

## 五、用例不等于一个测试点一行

一个用例可覆盖多个紧密相关的正向条件，但不要把互不相关的风险塞在一起。例如“注册成功”可以同时验证页面跳转和用户生成；但“注册成功 + SQL 注入 + 多浏览器兼容”应拆成不同用例，方便定位和统计。

## 六、示例：登录成功用例

| 字段 | 内容 |
|---|---|
| 编号 | LOGIN-ST-001 |
| 模块 | 用户管理/登录 |
| 标题 | 有效账号密码登录成功 |
| 优先级 | 高 |
| 前置条件 | 账号已注册且未锁定，服务正常 |
| 步骤 | 进入登录页；输入账号密码；点击登录 |
| 预期 | 登录成功，跳转首页；显示正确用户；生成有效会话 |
| 证据 | 截图、响应、请求 ID、用户状态 |

## 七、练习与答案

### 练习 1：改写标题

**题目**：将“测试密码框”改成可执行标题。

**答案**：例如“密码为空时点击登录，页面阻止提交并提示密码必填”。标题包含条件、动作和预期目标。

### 练习 2：发现用例问题

**题目**：用例步骤写“输入正确数据，结果正确”，问题在哪里？

**答案**：数据、入口、动作和“正确”都不可执行或不可判定。应写明具体账号/环境、页面路径、点击动作、状态码/页面变化/数据结果。

## 八、面试高频问法

**问：测试用例写得越多越好吗？**

**答**：不以数量为目标。应先保证需求和风险覆盖，再通过等价类、边界值、场景法减少重复；高价值用例要稳定、可执行、可维护，并根据变更影响更新。

## 九、课后任务

用课程资料中的 Excel 字段为登录、注册各写 5 条用例，要求编号唯一、步骤可复现、预期可判定，并给每条关联一个测试点。

### 课后任务参考答案

示例登录用例：`LOGIN-ST-001` 有效账号密码登录成功；`LOGIN-ST-002` 密码错误时拒绝登录；`LOGIN-ST-003` 账号为空时提示必填；`LOGIN-ST-004` 连续错误达到阈值后锁定；`LOGIN-ST-005` 退出后使用旧 Token 访问首页被拒绝。示例注册用例：合法数据成功、手机号格式错误、重复手机号、验证码过期、密码不符合复杂度。

每条用例都应补齐前置条件、输入数据、步骤、逐步预期、最终预期、优先级和证据。解析：成功/失败场景应分开，不能把“登录成功、错误密码、兼容性”塞进一条用例，否则执行结果和缺陷归因都会混乱。
